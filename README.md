# 🍜 Demo ระบบสั่งราเมงผ่านหน้าจอ Tablet (IsadRamen)

ระบบ Demo ร้านราเมงแบบ Eat-in สำหรับใช้งาน Local โดยจำลอง 3 ฝั่งหลัก: **Customer**, **Chef** และ **Cashier** พร้อมหน้าจอจำลองใบเสร็จ (Receipt), Food Slip และหน้าจอลูกค้า (Cashierจอลูกค้า) ตาม Wireframe `UI.png` และข้อกำหนดใน `ramen_demo_prompt.md`

---

## 🛠️ Tech Stack

- **Backend:** Node.js + Express.js 5
- **Database:** SQLite3 (`database/ramen.db` พร้อม schema และ seed อัตโนมัติ)
- **View Engine:** EJS Templates
- **Styling:** Tailwind CSS (Click/Touch-friendly Tablet Landscape UI)

---

## 🎯 Use Cases ทั้ง 9 ตัว

### Customer (ลูกค้า)
1. **ดูรายการอาหาร:** แสดงรายการอาหารตามหมวดหมู่ (ราเมง, ของทานเล่น, เครื่องดื่ม)
2. **เลือกรายการอาหาร:** กดเลือกอาหารเพื่อสั่ง ถ้าไม่ต้องปรับแต่ง (ของทานเล่น/เครื่องดื่ม) จะเพิ่มเข้า Order ทันที
3. **ปรับแต่งรายการอาหาร:** สำหรับราเมง เลือกความนุ่มเส้น, ซุป, เผ็ด, ต้นหอม และ Topping ด้วยปุ่มกด (ไม่มี Slider, ไม่มี Note)
4. **จัดการตะกร้าสินค้า & ยืนยันคำสั่งซื้อ:** เพิ่ม/ลด/ลบ/แก้ไขรายการในตะกร้า และกดยืนยันคำสั่งซื้อเพื่อส่งเข้าครัว
5. **ตรวจสอบประวัติรายการอาหารที่สั่ง:** ดูรายการอาหารทั้งหมดที่สั่งในรอบที่ยังไม่ชำระเงินของโต๊ะ

### Chef (ห้องครัว)
6. **รับคำสั่งซื้อเพื่อดำเนินการปรุงอาหาร:** เลือกรายการในคิวแล้วกด "รับคำสั่งซื้อ" (queue → prepare)
7. **อัปเดตสถานะรายการอาหาร:** อัปเดตสถานะเป็น "เสร็จสิ้น" (prepare → finish) และระบบจะสร้าง **Food Slip** จำลองทันที

### Cashier (แคชเชียร์)
8. **ดูรายการคำสั่งซื้อ:** สแกน/เลือก Payment Card ประจำโต๊ะ (CARD-01 ถึง CARD-20) เพื่อดึงและรวมยอดทุกออเดอร์ของโต๊ะ
9. **รับชำระเงิน:** รองรับเงินสดด้วย Numeric Keypad คำนวณเงินทอนอัตโนมัติ หรือ โอนเงินด้วย Mock QR พร้อมพิมพ์ใบเสร็จและ Reset โต๊ะ

## 🚀 วิธีติดตั้งและเริ่มต้นใช้งาน

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. รันระบบ (Development / Production)
```bash
npm run dev
# หรือ
npm start
```

ระบบจะรันบนพอร์ต `3000` เข้าใช้งานผ่านเว็บเบราว์เซอร์:
- **หน้าหลักเลือกระบบ (Demo Hub):** [http://localhost:3000](http://localhost:3000)
- **Customer Tablet (โต๊ะ T05):** [http://localhost:3000/customer/T05](http://localhost:3000/customer/T05)
- **Chef KDS (ห้องครัว):** [http://localhost:3000/chef](http://localhost:3000/chef)
- **Cashier POS (แคชเชียร์):** [http://localhost:3000/cashier](http://localhost:3000/cashier)
- **Cashier จอลูกค้า (Customer Display):** [http://localhost:3000/cashier/customer-display](http://localhost:3000/cashier/customer-display)

## 📁 โครงสร้างโปรเจกต์

```text

├── database/
│   ├── database.js          # เชื่อมต่อ SQLite และ Auto-Init
│   ├── ramen.db             # ไฟล์ฐานข้อมูล SQLite
│   ├── schema.sql           # โครงสร้างตารางตาม detail.md
│   └── seed.sql             # ข้อมูลเริ่มต้น (โต๊ะ 1-20, เมนู, ตัวเลือก, ท็อปปิ้ง)
├── public/
│   ├── css/
│   │   └── style.css        # สไตล์ Tailwind CSS
│   └── images/              # รูปภาพอาหารและ Mock QR Code
├── routes/
│   ├── customer.js          # จัดการ Flow ลูกค้าสั่งอาหาร (/customer/:tableNumber)
│   ├── chef.js              # จัดการ Flow ครัว KDS และ Food Slip (/chef)
│   ├── cashier.js           # จัดการ Flow แคชเชียร์และการชำระเงิน (/cashier)
│   └── scan.js              # ระบบแจกโต๊ะว่างอัตโนมัติ (/scan)
├── views/
│   ├── home.ejs             # หน้าแรกเลือกระบบ Demo Hub
│   ├── customer/
│   │   ├── start.ejs        # หน้าเริ่มต้น "กดเพื่อเลือกเมนู"
│   │   ├── menu.ejs         # หน้าเมนูหลัก + ตะกร้า + Customize Modal + รออาหารสักครู่
│   │   └── history.ejs      # ประวัติรายการอาหารที่สั่ง + นำ paymentcard ไปชำระ
│   ├── chef/
│   │   └── index.ejs        # หน้าจอครัว คิวอาหาร + ประวัติ + Food Slip
│   └── cashier/
│       ├── index.ejs        # แคชเชียร์ POS + Numeric Keypad + สแกนการ์ด + ใบเสร็จ
│       ├── customer-display.ejs # Cashier จอลูกค้าแสดง QR Code
│       └── receipt.ejs      # หน้าแสดงใบเสร็จรับเงิน
├── index.js                 # Server Entry Point

```
